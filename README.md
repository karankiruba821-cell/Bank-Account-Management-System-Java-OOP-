# 🏦 Bank Account Management System (Java OOP)

## 📌 Project Overview

This project is a simple **Bank Account Management System** developed using **Java Object-Oriented Programming (OOP)** concepts.

The program allows users to:

* Create a bank account
* Deposit money
* Withdraw money
* View account details

It demonstrates **Encapsulation using private variables and public getter/setter methods**.

---

## 🚀 Features

* Create a bank account with holder name, account number, and balance
* Deposit money into the account
* Withdraw money from the account
* Display account details
* Uses encapsulation to protect account data

---

## 🛠️ Technologies Used

* **Java**
* **Object-Oriented Programming (OOP)**

## ▶️ How to Run the Program

1. Clone the repository.
2. Open the project in a Java IDE or terminal.
3. Compile the program:

```bash
javac BankAccount.java
```

4. Run the program:

```bash
java BankAccount
```
